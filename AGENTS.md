# Repository Instructions

- Keep this repository safe for public viewing.
- Use synthetic people, companies, URLs, application records, and metrics in examples.
- Never add passwords, tokens, cookies, private resumes, recruiter conversations, or application
  evidence.
- Treat employer and client implementation details as confidential unless publication is approved.
- Keep the root `README.md` synchronized with structural or workflow changes.
- Run `pwsh -File .\scripts\validate-content.ps1` and
  `pwsh -File .\scripts\validate-applications.ps1` before committing.
- Rebuild `resumes/examples/example-resume.html` and `resumes/examples/example-resume.pdf` after
  changing the resume template, example data, or builder.
- Use PowerShell in Windows-facing instructions whenever practical.
